# Young-Research-Fellowship---Polaritonics
I am currently working on a B.Tech research project. The project aims to understand the properties of molecules inside an Optical cavity and try to tune various parameters like Rings currents, Charge transfer and Spin polarization.

I have attached the coding exercise that I initially used to simulate Jaynes Cumming Hamiltonian using only numpy without using QuTip. I have obtained the expected results for Polaritons.

I tried to replicate the work of Dr.Krishna Nandhipati and Dr.Orio Vendrell on Simulation of Symmetric molecules in Quantum optical cavities with Vibronic distortions using QuTip. I have obtained the expected results for the static case. The paper: [arXiv:2210.16037](https://arxiv.org/abs/2210.16037)

I tried to replicate the work of Dr.Sindhana Pannir-Sivajothi and Dr.David Limmer on Simulation of Spin polarization in Metal Donor-Acceptor system using Circularly polarized light. I have obtained the expected results. The paper: [arXiv:2512.05441](https://arxiv.org/abs/2512.05441)
